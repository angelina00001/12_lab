# Задание 10. Регулярное выражение — код номера отеля

## Задача

Валидировать **инвентарный код номера**: корпус (1–2 латинские буквы), этаж (1–2 цифры), номер на этаже (2–3 цифры).

## Паттерн

```regex
^[A-Z]{1,2}-\d{1,2}-\d{2,3}$
```

## Примеры

| Значение | Результат |
| --- | --- |
| `AB-3-12` | ✓ |
| `A-1-05` | ✓ |
| `101` | ✗ |
| `AB-3` | ✗ |
