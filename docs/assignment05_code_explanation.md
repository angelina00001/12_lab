# Задание 5. Объяснение сложного кода

Фрагмент: `backend/app/services/pricing.py`, функция `calculate_stay_price`.

## Простым языком

Функция считает итоговую стоимость проживания в отеле:

1. Считает **число ночей** между датой заезда и выезда. Если выезд не позже заезда — ошибка.
2. **Базовая сумма** = цена за ночь × количество ночей.
3. **Скидки**: за проживание от 7 ночей — 10%; для постоянного гостя — ещё 5%. Суммарная скидка не больше 20%.
4. **Наценка 15%** к базе в пиковый сезон (например, праздники).
5. **Штраф за поздний выезд**: первые 2 часа бесплатно, далее 500 ₽ за каждый час.
6. **Итог** = база − скидка + наценка + штраф.

## Пример

Номер 3500 ₽/ночь, 8 ночей, постоянный гость, пиковый сезон, 4 часа позднего выезда:

- База: 28 000 ₽  
- Скидка 15% (10% + 5%): −4 200 ₽  
- Пик +15%: +4 200 ₽  
- Штраф (4−2)×500: +1 000 ₽  
- **Итого: 29 000 ₽**
