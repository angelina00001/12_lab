# Задание 2 — Code Review сгенерированного кода

Формат: **Что сгенерировал ИИ → В чём проблема → Как исправил**

---

## 1. Сравнение дат уборки

**ИИ сгенерировал:** `CleaningTask.completed_at >= date.today()` в `reports.py`.

**Проблема:** Сравнение `datetime` с `date` в SQLite даёт неверные результаты и пропускает записи.

**Исправление:** Сравнение с `start_of_day` как `datetime` в UTC.

---

## 2. Жёстко заданный SECRET_KEY

**ИИ сгенерировал:** `secret_key: str = "change-me-in-production..."` только в config.

**Проблема:** Риск утечки JWT при деплое без переменных окружения.

**Исправление:** Чтение `DATABASE_URL` и `SECRET_KEY` из env в `database.py` и `conftest.py` для тестов.

---

## 3. Отсутствие проверки пересечения при обновлении брони

**ИИ сгенерировал:** PATCH бронирования без проверки занятости номера.

**Проблема:** Логическая ошибка — двойное бронирование одного номера.

**Исправление:** Вызов `has_overlapping_booking` при изменении дат в `routers/bookings.py`.

---

## 4. Удаление номера с бронированиями

**ИИ сгенерировал:** `db.delete(room)` без проверок.

**Проблема:** Нарушение целостности или каскадные сбои.

**Исправление:** HTTP 400, если у номера есть бронирования.

---

## 5. Отрицательная цена в API

**ИИ сгенерировал:** `price_per_night: float` без ограничений в первой версии схемы.

**Проблема:** Возможны отрицательные цены и некорректная выручка.

**Исправление:** Pydantic `Field(gt=0)` в `schemas/room.py` и проверка в `booking_service`.

---

## 6. Деактивация собственного admin-аккаунта

**ИИ сгенерировал:** endpoint деактивации без ограничений.

**Проблема:** Админ может заблокировать себя.

**Исправление:** Запрет `user_id == current.id` в `routers/admin.py`.

---

## 7. CORS по умолчанию `*`

**ИИ сгенерировал:** `allow_origins=["*"]` в черновике.

**Проблема:** Уязвимость при credentials.

**Исправление:** Явный список `localhost:5173` в `main.py`.
